## Which version to use

Give the October 28 change specification to the WindGroove web team. It reuses the approved W05–W08 values from the October 27 change guide and records which earlier findings the live site has since fixed. Use the October 27 W05–W08 change guide for the latest agreed changes to those four items. The merged Feishu document and October 26 workbook preserve the wording, values and status of their source records. They have not been rewritten to incorporate the later Product Q&A.
